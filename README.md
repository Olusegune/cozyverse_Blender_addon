# CozyVerse Builder

CozyVerse Builder is an offline-first Blender extension for creating editable stylized miniature worlds. This repository currently implements only the approved M0 and M1 foundation slice.

The foundation build provides:

- a native 3D View sidebar under the `CozyVerse` tab;
- scene-persistent prompt, preset, status, and last-run settings;
- extension preferences that enforce local demonstration mode;
- a deterministic local demo made from editable Blender objects;
- clean registration and unregistration;
- no network access, provider code, dynamic code execution, or paid requests.

See [INSTALL.md](INSTALL.md) for installation and verification. See [docs/audit-and-plan.md](docs/audit-and-plan.md) for the documentation audit, implementation state, roadmap, and milestone acceptance criteria.
