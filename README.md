# CozyVerse Builder

CozyVerse Builder is an offline-first Blender extension for creating editable stylized miniature worlds. Version 0.12.0 completes the Atmosphere Lab milestone with per-world lighting looks, practical-light controls, exposure, persistence, and preset migration.

The foundation build provides:

- a native 3D View sidebar under the `CozyVerse` tab;
- a reference-image preview, local palette extraction, and editable offline interpretation;
- safe filename indexing for Blender Asset Libraries and an optional local model folder;
- twelve curated visual styles, including Retro Sci-Fi, Solarpunk, Cozy Fantasy, Clay, Paper Craft, and Art Deco;
- a validated editable scene plan that is reviewed before Blender objects are created;
- non-destructive world versions with selection, framing, hiding, and manual-edit inspection;
- local asset categorization, matching, placement preview, and approved import into an editable quarantine collection;
- visibly distinct village, city, cafe, nature, space-outpost, market, farm, and fantasy construction families;
- visible Create, Atmosphere, Activity, and Settings workspaces;
- scene-persistent prompt, preset, status, and last-run settings;
- a full-area multiline prompt editor with wrapped sidebar preview;
- masked session-only Director, Tripo, and Meshy credential inputs for future provider adapters;
- reviewable, fingerprinted Tripo/Meshy request plans and a zero-cost mock generation workflow;
- a deterministic sari-sari-store diorama made from editable Blender-native objects;
- six functional atmosphere looks with time, sunlight, warmth, ambient light, exposure, practical-light intensity and 1,800–6,500 K color controls;
- per-world atmosphere persistence, saved-look loading, and automatic migration of version 1 presets;
- clean registration and unregistration;
- no network access, provider code, dynamic code execution, or paid requests.
