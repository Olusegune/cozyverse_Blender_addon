# CozyVerse UX redesign: audit, design, wireframes

Written 15 October 2026 against v0.17.0, after studying the screenshots of the live panel, the Prompt Composer dialog and the icon strip, and after reading `ui.py`, `visual_assets.py`, `properties.py` and the operators behind every button.

## Phase A: audit

### What is wrong (and why)

| # | Problem | Evidence | Root cause |
|---|---|---|---|
| 1 | **The prompt, the heart of the product, is a truncated one-line field.** The visible text is `Create a cozy mini…nd a diorama base.` | Screenshot 1 | `layout.prop(settings, "prompt")` is a single-line widget; Blender truncates the middle. The real multiline editor is three levels deep (Fine-tune → Open the big text editor) and the Composer is in a collapsed panel. |
| 2 | **Describe → Review → Build is hidden.** The default path skips Review entirely, and the Review step is behind an obscure checkbox. | Code: `review_before_build`, default off | v0.17 optimised for one-click magic and demoted the PRD's core flow. |
| 3 | **Competing actions.** `Conjure World`, a faded dice, `Plan with AI` (disabled), `Water/Land` dropdowns, `Style`, templates, all at once. | Screenshot 1 | No hierarchy: everything is on the first screen. |
| 4 | **Unlabeled icon navigation.** Seven icons, no words; the Create icon looks like a wall, Assets looks like a bar chart. | Screenshot 3 | `operator(text="", icon=…)` row. Settings and Activity sit beside creative tools. |
| 5 | **Images are small and swimming in empty space.** | Screenshot 1 | Blender previews are always square, but the art is 16:10 (templates, styles, seasons, stories), 16:9 (atmosphere, cinematic) and 3–4:1 (banner). Letterboxing wastes up to 37–60% of every cell. |
| 6 | **Engineer-speak.** "Conjure", "Preserve: 0", "Create: 27 / Changed: 13 / Delete: 0", "Ready for a local demonstration". | Review panel | Internal revision metrics shown to artists. |
| 7 | **`Plan with AI` shows a sentence of reasons** instead of a calm state. | Screenshot 1 | Raw reason string drawn as a label. |
| 8 | **Review needs a checkbox, then a button.** The confirmation is split in two. | Review panel | The approval flag is a separate property. |
| 9 | **The start screen cannot teach.** No stated promise, no steps. | Screenshot 1 | Header art only. |
| 10 | **Everything is one long scroll.** | All tabs | Progressive disclosure is only partial. |

### What already works and must survive

Offline Describe → Review → Build; the Prompt Composer dialog (screenshot 2 is good and stays); Style Studio presets; Atmosphere Lab, seasons, weather, clouds, water; Story Moments; Motion; cameras, postcard and clip; library; Director follow-ups; locks and recovery. None of this is rewritten. The redesign changes **what is shown, when, and how**.

## Native Blender limits, and how the design works within them

| Limit | How we work within it |
|---|---|
| No multiline text widget in panels | A **Prompt Studio**: a real Text Editor opens beside the 3D view (word-wrapped, large font) with a CozyVerse side panel (Done, Guide me, examples). The sidebar shows the **whole prompt, wrapped**, never truncated. |
| Previews are square | Ship **cover-cropped square** copies of the art, generated by a script from your originals, so images fill their cell edge to edge with no stretching. |
| Panels cannot be tiled galleries | **Large popup galleries** (Style Studio, Quick Start) with four-across big thumbnails; one click chooses and closes. |
| No arbitrary colours or fonts | Hierarchy through spacing, grouping, one accent button per step, muted secondary text, and imagery. |
| A custom GPU interface is costly and inaccessible | Not used. |
| A fully custom Blender *workspace* needs a shipped `.blend` layout and fragile region sizes | Not used. The **Prompt Studio split view and popup galleries** deliver the expanded space where it matters. |

## Phase B: design

### Information architecture

```
Describe  →  Review  →  Create
  (1)          (2)        (3)          one dominant action each

After Create:  "Customize your world"
   Atmosphere · Camera · Animation · Assets · Director · Export
   (labelled buttons, two across; each opens its tool with a "‹ Back" breadcrumb)
Settings (gear, top right) holds keys, folders, activity and recovery.
```

The seven-icon strip is gone. Tools are reached by **words**, only once there is a world to customise.

### Components

1. Step bar (3 buttons, current state) · 2. Prompt card · 3. Idea card (square image + label) · 4. Style summary row · 5. Fold-away "options" panels · 6. The single accent button + quiet secondary · 7. Plan summary with icon rows · 8. Success card · 9. Labelled tool grid + breadcrumb · 10. Popup galleries · 11. Prompt Studio.

### Microcopy

"Conjure World" → **Review My World** / **Build My World** (and "Build now, skip review"). "Ready for a local demonstration" → removed. "Plan with AI" → quiet row: *AI planning is off. Add a key in Settings to turn it on.* Revision metrics → "What will be built".
