# CozyVerse UI assets — Codex installation notes
- Use the exact file paths and ASSET_MANIFEST.json. Each PNG is an individual file, NOT a contact sheet.
- Blender's preview collections load image icons; do not embed the full-size artwork into narrow sidebar buttons.
- Template cards are 640x400, styles 512x320, atmosphere 512x288, onboarding 800x500, placeholders 320x320, icons 128x128.
- Assets come from earlier CozyVerse concept renders and programmatically created illustrations/icons. These are UI previews, **not** usable 3D models.
- Style comparisons are visually aligned around a café diorama but were generated separately; geometry/camera are not pixel-perfect identical.
- Generated logo artwork may contain dark pixels; verify transparency visually before using as an overlay. No promise of exact logo transparency.
- The custom icons are raster versions with native Blender icon fallback. Provider badges are unofficial visual indicators, not official provider marks.
- Optional premium graphics are simple generated UI states.
